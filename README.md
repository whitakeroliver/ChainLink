# ChainLink

ChainLink orchestrates decentralized data storage and smart contract execution on a blockchain edge network engine.

ChainLink is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- ChainLink orchestrates decentralized data storage
- and smart contract execution on

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/ChainLink.git`
2. `cd ChainLink`
3. Install in editable mode: `pip install -e .`

## Configuration

ChainLink is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
